## ✨ Overview

**Sukh Murti Mart** is a high-end, production-ready web application designed for a leading grocery and wholesale mart in Moradabad, India. Built with a focus on premium aesthetics and performance, it provides a seamless shopping bridge between the physical store and digital customers.

### 🌟 Key Features

- 💎 **Premium Glassmorphism UI**: A sophisticated design language using modern glass effects and vibrant emerald accents.
- 🌓 **Dynamic Dark Mode**: Fully responsive theme switching with rich matte/emerald gradients.
- 📱 **Mobile-First Experience**: Optimized for all devices with smooth haptic-like animations.
- 💬 **WhatsApp Integration**: Floating interactive contact button for instant customer-to-business ordering.
- 🚀 **High Performance**: Powered by TanStack Start and Vite for lightning-fast server-side rendering and hydration.
- 📍 **Local SEO Optimized**: Tailored metadata for the Moradabad wholesale and retail market.

## 🛠️ Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/start)
- **Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Routing**: [TanStack Router](https://tanstack.com/router)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### Prerequisites
- Node.js (Latest LTS)
- npm or bun

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Deepanshuthakur17/sukh-murti-mart.git
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```
